Self-hosted Personal Archive

DevVault 개발 계획서

라즈베리파이에 개발 자료, 강의 문서, 이미지, 코드 파일을 저장하고 폴더·태그·검색·미리보기·공유 기능으로 관리하는 셀프호스팅 개인 자료 아카이브.

1. 프로젝트 개요

사용자 본인 중심의 개인 사용자
서버 Ubuntu aarch64 라즈베리파이
핵심 가치 저장·검색·분류·백업
개발 기간 4주 MVP 기준

문제 정의

개발 자료와 강의 문서가 PC, 클라우드, 메신저, 다운로드 폴더 등에 흩어져 있어 필요한 자료를 다시 찾기 어렵다. 공개 클라우드에 개인 자료를 계속 올리는 대신, 직접 운영하는 라즈베리파이에 자료를 저장하고 통합 검색할 수 있는 환경이 필요하다.

서비스 한 줄 설명

개발자와 학습자가 자신의 자료를 안전하게 저장하고 빠르게 검색할 수 있는 셀프호스팅 개인 파일 아카이브.

2. 목표와 차별점

실사용

직접 사용하는 서비스

강의 PDF, Docker 설정, 프로젝트 문서, 이미지, 코드 파일을 실제로 저장한다.

포트폴리오

백엔드 역량 강조

대용량 업로드, 권한 검사, 검색, 비동기 처리, 백업과 장애 대응을 보여준다.

운영

라즈베리파이 배포

모든 서비스를 Docker Compose로 실행하고 Nginx, HTTPS, 영속 볼륨, Prometheus와 Grafana를 실제 운영 환경에 적용한다.

확장성

저장소 교체 가능 구조

로컬 디스크에서 MinIO 또는 S3로 변경할 수 있도록 StorageService를 분리한다.

차별화 포인트

  • 파일명뿐 아니라 태그, 설명, 확장자, 날짜, 크기로 검색
  • SHA-256 체크섬 기반 중복 파일 탐지
  • PDF·이미지·텍스트·코드 파일 미리보기
  • 만료 시간과 다운로드 횟수를 설정할 수 있는 공유 링크
  • 저장 공간 통계와 백업 상태 확인
  • 추후 OCR과 AI 자동 분류 기능 확장

8. 보안 계획

  • 파일명을 서버 저장 경로로 직접 사용하지 않기
  • UUID 기반 저장명 사용
  • 경로 조작 공격 차단
  • 확장자와 MIME 타입 동시 검사
  • 실행 파일과 위험한 스크립트 업로드 제한
  • 사용자별 파일 소유권 검사
  • 공유 토큰을 충분히 긴 난수로 생성
  • 공유 링크 비밀번호는 해시로 저장
  • 다운로드 응답에 적절한 Content-Disposition 설정
  • Nginx와 Spring 모두 업로드 크기 제한 적용
  • HTTPS 적용
  • 관리자 페이지와 /api/admin/**를 ROLE_ADMIN으로 제한
  • 관리자 역할 변경·사용자 상태 변경·파일 삭제 작업 감사 로그 기록
  • 관리자가 자신의 마지막 ROLE_ADMIN 권한을 제거하지 못하도록 제한
라즈베리파이를 인터넷에 직접 노출하므로 기본 계정 제거, SSH 키 인증, 방화벽 설정, 정기 업데이트, 포트 최소 공개가 필요하다.

11. 배포와 운영 계획

services:
  frontend:
    build: ./frontend
    restart: unless-stopped

  backend:
    build: ./backend
    restart: unless-stopped
    volumes:
      - ./data/uploads:/data/uploads

  mysql:
    image: mysql:8.0
    restart: unless-stopped
    volumes:
      - mysql-data:/var/lib/mysql

  nginx:
    image: nginx:alpine
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"

  prometheus:
    image: prom/prometheus
    restart: unless-stopped
    command: --storage.tsdb.retention.time=15d
    volumes:
      - ./monitoring/prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - prometheus-data:/prometheus

  grafana:
    image: grafana/grafana
    restart: unless-stopped
    volumes:
      - grafana-data:/var/lib/grafana

  node-exporter:
    image: prom/node-exporter
    restart: unless-stopped

  cadvisor:
    image: gcr.io/cadvisor/cadvisor
    restart: unless-stopped
    privileged: true
    volumes:
      - /:/rootfs:ro
      - /var/run:/var/run:ro
      - /sys:/sys:ro
      - /var/lib/docker:/var/lib/docker:ro

volumes:
  mysql-data:
  prometheus-data:
  grafana-data:
외부에는 Nginx의 80·443 포트만 공개한다. Backend, MySQL, Prometheus, Grafana는 Docker 내부 네트워크에서만 접근하고 Grafana가 필요하면 Nginx를 통해 인증 후 노출한다.

GitHub Actions CI/CD

Pull Request / Push
  └─ CI: Gradle 테스트

main 브랜치 Push + CI 성공
  └─ CD: linux/arm64 이미지 빌드
       └─ GHCR 푸시
            └─ SSH로 라즈베리파이 접속
                 └─ docker compose pull && docker compose up -d
워크플로는 .github/workflows/ci.yml과 deploy.yml로 분리한다. 서버 주소, 사용자명, SSH 키는 GitHub Actions Secrets에 저장하고 저장소에는 커밋하지 않는다.

운영 체크리스트

  • GitHub Actions CI 통과 후에만 배포 실행
  • PI_HOST, PI_USER, PI_SSH_KEY Secrets 등록
  • DuckDNS 도메인 연결
  • Let's Encrypt 인증서 적용
  • Docker 볼륨 영속성 확인
  • 사용 이미지의 linux/arm64 지원 확인
  • 일일 DB 백업
  • 주간 파일 증분 백업
  • 디스크 사용량 80% 초과 알림
  • CPU 온도, 메모리, JVM, API 오류율 대시보드 구성
  • 관리자 작업 감사 로그와 운영 상태 화면 확인
  • Prometheus 데이터 보존 기간 15일 적용
  • 백엔드 헬스 체크

운영 성공 기준: 라즈베리파이를 재부팅해도 모든 컨테이너가 자동으로 실행되고, 기존 파일과 DB 데이터가 유지되며, HTTPS 주소로 정상 접근할 수 있어야 한다.

12. 포트폴리오 정리 방향

프로젝트 소개 문구

라즈베리파이에 흩어진 개발 자료와 강의 문서를 통합 저장·검색하기 위해 셀프호스팅 개인 자료 아카이브를 개발했습니다. 파일 메타데이터 관리, 계층형 폴더, 태그 검색, 중복 파일 탐지, 공유 링크, 미리보기, 백업 기능을 구현하고 Docker Compose와 Nginx를 이용해 실제 홈서버에 배포했습니다.

강조할 기술적 문제

  • 파일 저장과 DB 저장의 트랜잭션 불일치 처리
  • 권한 없는 파일 접근 방지
  • 대용량 파일 업로드와 스트리밍 다운로드
  • 계층형 폴더 구조와 검색 성능
  • SHA-256 기반 중복 탐지
  • 라즈베리파이의 제한된 디스크·메모리 환경 최적화
  • 실제 백업과 장애 복구 경험
